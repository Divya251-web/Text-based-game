# The Lost Key 

## About the Project
The Lost Key is a simple text-based adventure game made using HTML, CSS, and JavaScript. In this game, the player has to explore different rooms, find a key, unlock a door, and escape from the house.

The game works through simple text commands. Players can move between rooms, pick up items, check their inventory, and use items whenever needed.

## Features
- Explore different rooms.
- Find and collect items.
- Check your inventory.
- Unlock doors using keys.
- Interact with the game using text commands.
- Get a winning message after escaping.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Open `index.html` in your web browser.
2. Type `help` to see the available commands.
3. Start by finding the rusty key in your bedroom.
4. Move to the hallway and unlock the door.
5. Reach outside to complete the game.

## Commands

| Command | Use |
|---|---|
| `look` | See your current room |
| `go north` | Move north |
| `go south` | Move south |
| `go east` | Move east |
| `go west` | Move west |
| `take [item]` | Pick up an item |
| `use [item]` | Use an item |
| `inventory` | Check collected items |
| `help` | See all commands |
